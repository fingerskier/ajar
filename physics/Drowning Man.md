# The Drowning Man

Suppose you are on the beach and someone is drowning in the ocean nearby.
The shortest path to save them is not a straight line because you run faster than you swim.
The optimal path is mostly running and some swimming;
from above this path is two segments.

Light travels that same kind of path when traversing different media from point A to point B;
because it changes speed in different densities.
But light does not _know_ it is traveling to point B- it just gets there by the least energetic path.
And a multitude of other photons get to surrounding points, from A, similarly.
